### 💻 Мои ключевые проекты:

#### 🤖 [ИИ-Ассистент для нотариуса](ссылка_на_репозиторий_или_демо)
Умное веб-приложение для автоматизации юридической рутины.
*   **Функционал:** Генерация документов по текстовому описанию с помощью нейросетей, точный калькулятор госпошлин, база клиентов.
*   **Стек:** Python, ИИ-интеграции, PostgreSQL.

#### 🚚 [Дашборд логистики «Моя Логистика»](ссылка_на_репозиторий_или_демо)
Система управления процессами пивоваренного завода.
*   **Функционал:** Учет клиентов, заказов, водителей и маршрутов. Отслеживание возвратной тары (кег) в реальном времени.
*   **Стек:** Python, HTML/CSS/JS, Базы данных.

#### 📊 [Веб-планировщик Brew Clone](ссылка_на_репозиторий_или_демо)
Сервис для планирования производственных процессов.
*   **Функционал:** Интерактивная диаграмма Ганта, расчет ресурсов, управление складскими остатками, адаптивный дизайн.
*   **Стек:** Python, JavaScript, SQLite.

#### 🚗 [CRM для автосервиса](ссылка_на_репозиторий_или_демо)
Система автоматизации для СТО.
*   **Функционал:** Замена бумажных журналов, ведение базы заявок, учет выполненных работ, распределение задач между мастерами.
*   **Стек:** Python, Реляционные БД.

#### 🌐 [Сайт-визитка для нотариуса](ссылка_на_репозиторий_или_демо)
Представительский лендинг для частного специалиста.
*   **Функционал:** Понятная структура услуг, адаптивная верстка, формы обратной связи с валидацией.
*   **Стек:** Python, HTML5, CSS3.
